# Консольная ролевая игра по мотивам Dungeons & Dragons (C++) 🧙‍♂️

Индивидуальный проект текстовой ролевой игры (Text-based RPG), вдохновленной правилами 5-й редакции D&D, реализованный на языке C++ с применением принципов объектно-ориентированного программирования (ООП).

---

## 📌 Особенности проекта

- **Создание и развитие персонажа:**
  - Выбор классических рас D&D (*Человек, Эльф, Дварф, Полурослик, Полуорк, Полуэльф, Драконорождённый, Гном, Тифлинг*) с автоматическим расчётом расовых бонусов к характеристикам.
  - Выбор классов (*Воин, Маг, Плут, Жрец, Варвар, Бард, Друид, Следопыт, Паладин, Чародей, Колдун, Монах*) со стартовой экипировкой.
  - Настройка базовых характеристик (Сила, Ловкость, Телосложение, Интеллект, Мудрость, Харизма) и расчёт зависимых параметров (ХП, Мана, Выносливость, Урон, Защита).
- **Инвентарь и экипировка:**
  - Раздельные слоты экипировки для оружия и доспехов.
  - Система зелий с восстановлением здоровья, маны и выносливости.
  - Квестовые предметы и управление золотом.
- **Торговля и взаимодействие с NPC:**
  - Полноценный торговец (Боб) с динамическим ассортиментом товаров, возможностью покупки и продажи предметов, проверкой золота у игрока и торговца.
- **Игровая энциклопедия:**
  - Встроенный справочник по расам, классам, оружию, доспехам и зельям.
- **ASCII-арт графика:**
  - Графическое оформление меню, персонажей, экрана создания героя и магазина.
- **Корректная работа с кириллицей (UTF-8):**
  - Полная русификация всех элементов интерфейса, диалогов и справочников.
  - Корректное отображение в консоли Windows через Windows API (`SetConsoleOutputCP(CP_UTF8)`) без искажений кодировки и кракозябр.

## 🏗 Архитектура и структура классов

Проект построен с разделением на заголовочные файлы (`headers/`), реализацию логики (`drivers/`) и конфигурационные данные (`data/`):

```
Console-DnD/
├── headers/             # Заголовочные файлы (.h)
│   ├── Character.h      # Класс игрового персонажа
│   ├── Stats.h          # Характеристики персонажа
│   ├── Race.h           # Модель расы D&D
│   ├── Class.h          # Модель класса D&D
│   ├── Item.h           # Базовый класс игрового предмета
│   ├── Weapon.h         # Оружие (наследник Item)
│   ├── Armor.h          # Доспехи (наследник Item)
│   ├── Consumable.h     # Расходуемые предметы (наследник Item)
│   ├── Potion.h         # Зелья (наследник Consumable)
│   ├── QuestItem.h      # Квестовые предметы (наследник Item)
│   ├── Inventory.h      # Инвентарь
│   ├── NPC.h            # Базовый класс NPC
│   ├── Merchant.h       # Торговец (наследник NPC)
│   └── Menu.h           # Меню игры
├── drivers/             # Реализация методов (.cc)
│   ├── Initializer.cc   # Загрузка игровых данных из JSON
│   ├── Functions.cc     # Утилиты консоли (очистка экрана, пауза, UTF-8)
│   ├── Ascii.cc         # Загрузка ASCII-артов
│   └── ...
├── data/                # Конфигурационные файлы в формате JSON
│   ├── races.json       # Описание рас и их модификаторов
│   ├── classes.json     # Описание классов и стартового снаряжения
│   ├── weapons.json     # Каталог оружия
│   ├── armors.json      # Каталог доспехов
│   └── potions.json     # Каталог зелий
├── asciiArt/            # Текстовая графика
├── nlohmann/            # Библиотека работы с JSON для C++
├── CMakeLists.txt       # Конфигурация сборки CMake
├── build.bat            # Скрипт автоматической сборки для Windows
├── run.bat              # Скрипт запуска игры с правильной кодировкой
└── main.cpp             # Точка входа в программу
```

### Основные концепции ООП в проекте:
1. **Инкапсуляция:** поля классов защищены модификаторами доступа `private`/`protected`, доступ осуществляется через геттеры и сеттеры с валидацией.
2. **Наследование:** иерархия предметов `Item -> Weapon / Armor / Consumable -> Potion` и персонажей `NPC -> Merchant`.
3. **Полиморфизм:** переопределение методов строкового представления `toString()` для различных игровых сущностей.

## ⚙️ Требования для сборки

- **ОС:** Windows 10 / 11 (или Linux / macOS)
- **Компилятор:** Поддержка C++17 (MSVC cl.exe из состава Visual Studio 2019/2022, MinGW g++, либо Clang)
- **CMake** (опционально, версии 3.15+)

---

## 🚀 Сборка и запуск

### Вариант 1. Быстрая сборка через `build.bat` (Рекомендуется для Windows)
Просто запустите скрипт сборки:
```cmd
build.bat
```
Скрипт автоматически найдет установленный компилятор Visual Studio (MSVC) или MinGW, настроит флаги кодировки `/utf-8` и стандарт `C++17`, и соберет исполняемый файл `game.exe`.

### Вариант 2. Сборка через CMake
```cmd
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

### Вариант 3. Ручная сборка через командную строку
- **MSVC (Visual Studio):**
  ```cmd
  cl.exe /EHsc /std:c++17 /utf-8 /I. main.cpp /Fe:game.exe
  ```
- **GCC / MinGW:**
  ```cmd
  g++ -std=c++17 -finput-charset=UTF-8 -fexec-charset=UTF-8 -I. main.cpp -o game.exe
  ```

---

## 🎮 Запуск игры

Для корректного отображения шрифтов и кириллицы запускайте игру через:
```cmd
run.bat
```
*(Или напрямую `game.exe`, если ваша консоль настроена на работу с UTF-8 кодировкой `chcp 65001`).*
